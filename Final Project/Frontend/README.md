This folder contains the **frontend implementation** of the Bike Rental Prediction System, built using **Streamlit**.  
It provides an interactive user interface to predict **daily and hourly bike demand** using pre-trained machine learning models.





## Folder Structure

```text
frontend/
│
├── app.py              # Main Streamlit application
├── day_model.pkl       # Trained ML model for daily demand prediction
├── hour_model.pkl      # Trained ML model for hourly demand prediction
├── bg.png              # Background image used in the UI
├── wallpaper.png       # UI wallpaper / styling image
├── requirements.txt    # Required Python dependencies
